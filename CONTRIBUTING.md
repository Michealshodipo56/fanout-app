# Contributing to Fanout Application Monorepo

Thank you for helping build Fanout!

## Monorepo Standards

1. Use `pnpm` workspaces for package management.
2. Maintain strict TypeScript compilation across all apps and packages.
3. Use modular component design in `packages/ui`.
4. Ensure all financial calculations use basis points or verified base unit conversion functions.

## Pull Request Process

1. Create a feature branch off `main`.
2. Verify `pnpm build` completes without errors.
3. Submit a Pull Request.
